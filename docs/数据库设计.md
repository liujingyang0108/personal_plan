# 数据库集合设计

## 概述

本项目使用微信云开发数据库，包含五个核心集合，用于存储个人精进工具的所有数据。

---

## 集合清单

### 1. goals（目标表）

存储四维度目标信息。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| _id | ObjectId | 是 | 自动生成 |
| category | string | 是 | 目标维度：fitness/finance/learning/work |
| title | string | 是 | 目标标题 |
| description | string | 否 | 目标详细描述 |
| start_date | string | 否 | 开始日期，格式 YYYY-MM-DD |
| end_date | string | 否 | 结束日期，格式 YYYY-MM-DD |
| status | string | 是 | 状态：进行中/已完成/暂停 |
| ai_plan | string | 否 | AI 生成的计划内容 |
| created_at | Date | 是 | 创建时间 |

**索引**：
- category（查询筛选）
- status（状态筛选）
- created_at（排序）

---

### 2. daily_intentions（每日意图表）

存储每日意图/任务。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| _id | ObjectId | 是 | 自动生成 |
| date | string | 是 | 日期，格式 YYYY-MM-DD |
| title | string | 是 | 意图内容 |
| category | string | 是 | 所属维度：fitness/finance/learning/work |
| goal_id | string | 否 | 关联目标 ID |
| is_completed | boolean | 是 | 是否完成 |
| is_locked | boolean | 是 | 是否锁定 |
| created_at | Date | 是 | 创建时间 |

**索引**：
- date（按日期查询）
- category（维度筛选）
- is_completed（完成状态筛选）

---

### 3. focus_sessions（专注记录表）

存储每次专注会话的记录。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| _id | ObjectId | 是 | 自动生成 |
| intention_id | string | 否 | 关联的意图 ID |
| start_time | Date | 是 | 开始时间 |
| end_time | Date | 否 | 结束时间 |
| actual_duration | number | 否 | 实际专注时长（秒） |
| distraction_minutes | number | 否 | 分心时长（分钟） |
| distraction_reason | string | 否 | 分心原因 |
| created_at | Date | 是 | 创建时间 |

**索引**：
- intention_id（关联查询）
- created_at（按时间排序）

---

### 4. trainings（训练记录表）

存储每次训练记录。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| _id | ObjectId | 是 | 自动生成 |
| date | string | 是 | 训练日期，格式 YYYY-MM-DD |
| template_name | string | 是 | 模板名称：推/拉/腿/全身 |
| exercises | Array | 是 | 动作数组 |
| created_at | Date | 是 | 创建时间 |

**exercises 子对象结构**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| exercise_name | string | 动作名称 |
| sets | Array | 组数数组 |

**sets 子对象结构**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| set_number | number | 组序号 |
| weight | number | 重量（kg） |
| reps | number | 次数 |
| is_completed | boolean | 是否完成 |

**索引**：
- date（按日期查询）
- template_name（模板筛选）
- created_at（排序）

---

### 5. distraction_log（分心账本）

存储分心记录。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| _id | ObjectId | 是 | 自动生成 |
| date | string | 是 | 日期，格式 YYYY-MM-DD |
| duration_minutes | number | 是 | 分心时长（分钟） |
| reason | string | 否 | 分心原因 |
| created_at | Date | 是 | 创建时间 |

**索引**：
- date（按日期查询）
- reason（原因统计）

---

## 创建指引

### 通过微信开发者工具创建集合

1. 打开微信开发者工具
2. 进入云开发控制台
3. 选择"数据库"标签
4. 点击"新建集合"，分别创建上述五个集合
5. 为集合添加索引（如上所述）

### 通过云函数初始化集合（可选）

可以创建云函数来自动初始化集合结构。

---

## 数据操作示例

### 添加目标

```javascript
const db = wx.cloud.database();
await db.collection('goals').add({
  data: {
    category: 'fitness',
    title: '12月前完成半马',
    description: '每天跑步5公里，逐步增加里程',
    start_date: '2024-01-01',
    end_date: '2024-12-31',
    status: '进行中',
    created_at: new Date()
  }
});
```

### 查询今日意图

```javascript
const today = new Date().toISOString().split('T')[0];
const intentions = await db.collection('daily_intentions')
  .where({ date: today })
  .get();
```

### 添加训练记录

```javascript
await db.collection('trainings').add({
  data: {
    date: '2024-01-15',
    template_name: '推',
    exercises: [
      {
        exercise_name: '卧推',
        sets: [
          { set_number: 1, weight: 60, reps: 10, is_completed: true },
          { set_number: 2, weight: 60, reps: 10, is_completed: true }
        ]
      }
    ],
    created_at: new Date()
  }
});
```
